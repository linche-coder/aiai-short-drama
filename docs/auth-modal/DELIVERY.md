# 登录注册弹窗与验收问题修订交付

更新：2026-09-17

## 正式界面已完成

- 全站共享登录、注册、找回密码弹窗，背景保留触发页面。
- 桌面宽度 456px，手机左右 12px 留白；超高内容在面板内部滚动。
- 登录：账号、密码、独立显隐、忘记密码、辅助说明、提交状态和错误状态。
- 注册：4–20 位英文/数字/下划线账号、8–64 位密码、确认密码、独立显隐、选填邮箱、找回提醒和自动登录说明。
- 路由兼容：原 `/account/*?returnTo=...` 深链接继续可用；外部 URL、双斜线、反斜线和账号路由循环均回退首页。
- 弹窗支持关闭按钮、Escape、遮罩关闭、焦点循环、背景滚动锁定和浏览器返回。
- 登录/注册弹窗已移除重复的“用户登录注册”标题，仅保留品牌 Logo 与模式切换。
- 登录后的页头统一使用头像入口：免费用户为深色描边头像，会员为粉紫光环头像并带皇冠角标；个人中心显示实际账号，不展示“体验账号”文案。
- 个人中心所有子页统一使用同宽导航容器；个人资料页可上传 JPG、PNG 或 WebP 头像并恢复默认，默认头像显示用户名首字母。
- 会员用户从页头“会员”和个人中心“会员中心”进入同一会员中心；页面包含有效期、V3 等级、成长进度、已实现权益、订单/帮助入口和续费方案。免费用户仍进入方案选择页。
- 受限剧集会员提示已移除底部文字“关闭”，两个操作按钮使用独立按钮组与 14px 间距；右上角关闭图标、Escape 和遮罩关闭仍可用。
- 会员、收银台、受限集提示、评论、反馈、个人中心导航、空状态和帮助中心已按本轮任务书调整。
- 普通界面不显示测试身份、沙盒订单、回调模拟器、签名密钥或验收说明。
- 演示彩条不再进入播放路径；生产构建继续移除 `dist/media/demo`。

## 真实业务接通状态

- 前端已调用 `/api/v1/auth/sign-in`、`/api/v1/auth/register`、`/api/v1/auth/password-reset` 和 `/api/v1/session`。
- 登录和注册只有在接口返回有效会话后才更新登录状态并回跳。
- 注册接口字段为 `account`、`password`、可选 `email`；空邮箱不会发送。
- 评论、举报、反馈和订单读取保留真实 HTTP 契约，接口失败显示不可用，不写入本地数据冒充成功。
- 当前仓库没有认证服务器、数据库、支付商户或正式媒体服务，因此本地预览中的真实业务动作会返回“暂时不可用”。

## 外部依赖未完成

- 账号数据库、密码哈希、账号冲突检查、HttpOnly 会话 Cookie、CSRF 和设备注销。
- 邮箱提供商、发件域名、限时单次重置令牌。
- 正式逐集媒体、授权证明、播放签名和 CDN。
- 支付商户、服务端报价、支付页面、签名回调、退款与最终会员商业规则。
- 评论、收藏、历史、消息、工单的服务端持久化与行级权限。
- 头像目前保存在当前设备；跨设备头像同步仍需账号服务、对象存储和服务端图片安全处理。
- 运营主体、联系方式、资质、生效日期及最终协议审核。
